# BARKVERSE Roadmap

## P0 — Must ship

- Dog Discovery
- Google AI personality generation
- BARKVERSE home
- Human Investigation Bureau
- Dog dialogue
- ElevenLabs voice
- responsive polished UI
- deployment
- GitHub documentation
- DEV submission

## P1 — Should ship

- Memory Vault
- Solana Pawprint
- Barkcade
- strong loading/error states
- polished animations

## P2 — Ship only if stable

- Snowflake Observatory
- additional games
- additional dog-world locations
- advanced sharing

## Cut rule

Anything that does not improve the core experience, creates instability, or exists only to demonstrate a technology is cut first.

## Demo sequence

1. Hook: What if dogs had their own internet?
2. Upload dog.
3. AI creates identity.
4. Enter BARKVERSE.
5. Investigate a funny human case.
6. Ask the dog a question and hear it speak.
7. Create a memory.
8. Create Pawprint.
9. Show Observatory.
10. Close with the product thesis.
