# BARKVERSE

> What if dogs had their own internet?

BARKVERSE is a playful, AI-powered dog civilization built for the DEV Weekend Challenge: Dog Days Edition.

## Competition target

- Overall winner
- Best use of Google AI
- Best use of ElevenLabs
- Best use of Solana
- Best use of Snowflake

## MVP journey

Upload dog → discover personality → enter BARKVERSE → investigate/play → talk to dog → preserve a memory → optional Pawprint.

## Architecture

Google AI is the primary intelligence layer. OpenRouter `openrouter/free` is the provider fallback where capability-compatible. ElevenLabs provides dog voice. Solana provides the Pawprint proof layer. Snowflake powers anonymized Barkverse Observatory analytics.
